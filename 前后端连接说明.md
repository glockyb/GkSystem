## 🏗️ 连接架构

### 整体架构

```
┌─────────────────┐
│   用户浏览器     │
└────────┬────────┘
         │ HTTP/HTTPS
         ▼
┌─────────────────────────────────────────┐
│        前端 (Vue 3 + Vite)              │
│  ┌───────────────────────────────────┐ │
│  │  /api/* 请求                      │ │
│  │  ↓                                │ │
│  │  axios (自动添加Token)            │ │
│  └───────────────────────────────────┘ │
└────────┬───────────────────────────────┘
         │
         │ 开发环境: Vite Proxy
         │ 生产环境: Nginx Proxy
         ▼
┌─────────────────────────────────────────┐
│       后端 (Flask RESTful API)          │
│  ┌───────────────────────────────────┐ │
│  │  /api/v1/* 路由                   │ │
│  │  ↓                                │ │
│  │  JWT Token验证                    │ │
│  │  ↓                                │ │
│  │  业务逻辑处理                     │ │
│  │  ↓                                │ │
│  │  返回JSON响应                     │ │
│  └───────────────────────────────────┘ │
└─────────────────────────────────────────┘
```

## 🔄 API通信流程

### 1. 开发环境连接

#### 前端配置 (`frontend/vite.config.js`)

```javascript
export default defineConfig({
  server: {
    port: 8080,
    proxy: {
      '/api': {
        target: 'http://localhost:5000',  // 后端地址
        changeOrigin: true,
        rewrite: (path) => path  // 保持路径不变
      }
    }
  }
})
```

**工作原理：**
- 前端在 `http://localhost:8080` 运行
- 所有 `/api/*` 请求被代理到 `http://localhost:5000`
- Vite 自动处理跨域问题

#### 后端配置 (`backend/app.py`)

```python
# 启用CORS（跨域资源共享）
CORS(app, resources={r"/api/*": {"origins": "*"}})

# 注册API路由
app.register_blueprint(auth.bp, url_prefix='/api/v1')
app.register_blueprint(dishes.bp, url_prefix='/api/v1')
app.register_blueprint(recommendations.bp, url_prefix='/api/v1')
app.register_blueprint(ratings.bp, url_prefix='/api/v1')
```

### 2. 生产环境连接（Docker）

#### Nginx配置 (`frontend/nginx.conf`)

```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    # 前端静态资源
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api {
        proxy_pass http://backend:5000/api;  # Docker容器间通信
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }
}
```

**工作原理：**
- Nginx 作为反向代理服务器
- 前端请求 `/api/*` 被代理到 `backend:5000`（Docker内部网络）
- 用户访问 `http://your-domain.com`，所有请求都通过 Nginx 路由

## 🔐 认证机制

### JWT Token认证

#### 1. 登录流程

```javascript
// 前端 (frontend/src/views/Login.vue)
const handleLogin = async () => {
  const response = await api.auth.login({
    username: 'testuser',
    password: 'password'
  })
  
  // 返回数据: { token, user_id, username }
  userStore.login(response)  // 保存Token到localStorage
}
```

```python
# 后端 (backend/api/auth.py)
@bp.route('/login', methods=['POST'])
def login():
    data = request.get_json()
    username = data.get('username')
    password = data.get('password')
    
    # 验证用户
    user = authenticate_user(username, password)
    
    # 生成JWT Token
    access_token = create_access_token(identity=user['id'])
    
    return jsonify({
        'token': access_token,
        'user_id': user['id'],
        'username': user['username']
    })
```

#### 2. Token存储和使用

**前端存储：**
```javascript
// frontend/src/store/user.js
login(response) {
  localStorage.setItem('token', response.token)
  localStorage.setItem('user_id', response.user_id)
  this.token = response.token
  this.user_id = response.user_id
}
```

**自动添加Token：**
```javascript
// frontend/src/api/index.js
api.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})
```

**后端验证：**
```python
# backend/api/recommendations.py
@bp.route('/recommendations', methods=['GET'])
@jwt_required()  # 需要Token
def get_recommendations():
    user_id = get_jwt_identity()  # 从Token获取用户ID
    # ... 推荐逻辑
```

#### 3. Token过期处理

```javascript
// frontend/src/api/index.js
api.interceptors.response.use(
  response => response.data,
  error => {
    if (error.response?.status === 401) {
      // Token过期或无效
      localStorage.removeItem('token')
      localStorage.removeItem('user_id')
      window.location.href = '/login'
    }
    return Promise.reject(error)
  }
)
```

## 📊 数据格式

### 请求格式

#### 1. POST请求（JSON）

```javascript
// 前端
await api.auth.login({
  username: 'testuser',
  password: 'password'
})

// HTTP请求
POST /api/v1/login HTTP/1.1
Host: localhost:5000
Content-Type: application/json

{
  "username": "testuser",
  "password": "password"
}
```

#### 2. GET请求（Query参数）

```javascript
// 前端
await api.dishes.getList({
  page: 1,
  per_page: 20,
  category: '荤菜',
  search: '红烧'
})

// HTTP请求
GET /api/v1/dishes?page=1&per_page=20&category=荤菜&search=红烧 HTTP/1.1
Host: localhost:5000
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

#### 3. 带Token的请求

```javascript
// 前端自动添加
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

// 后端验证
from flask_jwt_extended import jwt_required, get_jwt_identity

@jwt_required()
def get_recommendations():
    user_id = get_jwt_identity()  # 从Token获取user_id
```

### 响应格式

#### 1. 成功响应

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user_id": 1,
  "username": "testuser"
}
```

#### 2. 列表响应

```json
{
  "dishes": [
    {
      "id": 1,
      "name": "红烧肉",
      "category": "荤菜",
      "price": 12.00,
      "description": "经典红烧肉",
      "image_url": "/images/hongshaorou.jpg"
    }
  ],
  "total": 100,
  "page": 1,
  "per_page": 20
}
```

#### 3. 错误响应

```json
{
  "error": "用户名或密码错误"
}
```

HTTP状态码：
- `200`: 成功
- `201`: 创建成功
- `400`: 请求错误
- `401`: 未授权（需要登录）
- `404`: 资源不存在
- `500`: 服务器错误

## 🛡️ 错误处理

### 前端错误处理

```javascript
// frontend/src/api/index.js

// 请求拦截器 - 添加Token
api.interceptors.request.use(
  config => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)

// 响应拦截器 - 统一处理错误
api.interceptors.response.use(
  response => {
    return response.data  // 直接返回data部分
  },
  error => {
    // 401: Token过期或无效
    if (error.response?.status === 401) {
      localStorage.removeItem('token')
      window.location.href = '/login'
      return Promise.reject(new Error('请重新登录'))
    }
    
    // 其他错误
    const message = error.response?.data?.error || error.message || '请求失败'
    ElMessage.error(message)
    return Promise.reject(error)
  }
)
```

### 后端错误处理

```python
# backend/api/recommendations.py
from flask import jsonify

@bp.route('/recommendations', methods=['GET'])
@jwt_required()
def get_recommendations():
    try:
        user_id = get_jwt_identity()
        recommendations = recommender.recommend(user_id, n=10)
        return jsonify({'dishes': recommendations}), 200
    except Exception as e:
        return jsonify({'error': str(e)}), 500
```

## 🔌 API端点总结

| 方法 | 路径 | 说明 | 需要Token | 请求体 |
|------|------|------|-----------|--------|
| POST | `/register` | 用户注册 | ❌ | `{username, password, email}` |
| POST | `/login` | 用户登录 | ❌ | `{username, password}` |
| GET | `/profile` | 获取用户信息 | ✅ | - |

### 菜品相关

| 方法 | 路径 | 说明 | 需要Token | 请求体 |
|------|------|------|-----------|--------|
| GET | `/dishes` | 获取菜品列表 | ❌ | Query: `page, per_page, category, search` |
| GET | `/dishes/:id` | 获取菜品详情 | ❌ | - |
| GET | `/dishes/categories` | 获取分类列表 | ❌ | - |

### 推荐相关

| 方法 | 路径 | 说明 | 需要Token | 请求体 |
|------|------|------|-----------|--------|

- **存储位置**：`localStorage`

### 4. 数据验证

- **前端验证**：表单验证、类型检查
